## Single-cell analysis of head and neck cancer (GSE139324)

A Seurat analysis of the public single-cell RNA-seq dataset [GSE139324](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE139324) from NCBI GEO, a study of immune cells in head and neck squamous cell carcinoma.

Steps: quality control, normalization, variable genes, PCA, clustering, UMAP and marker genes per cluster.

Tools: R, Seurat, Matrix, tidyverse.
